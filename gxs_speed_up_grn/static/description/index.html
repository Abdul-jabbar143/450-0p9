Overview

The gxs_speed_up_grn module is designed to enhance the performance and efficiency of the stock management system in Odoo. Specifically, it aims to improve the processing speed of Goods Receipt Notes (GRNs) that contain more than 500 lines.

Key Features

  • Optimizes the creation and updating of stock quantities.
  • Introduces batch processing techniques to handle large GRNs efficiently.
  • Utilizes direct SQL insertion to speed up the creation of stock quants.
  • Ensures that stock move lines are processed quickly and accurately.

Technical Details

This module modifies the core functionality of the stock management system to improve performance. The main improvements include:

  • Using direct SQL insertion for creating stock quant records, significantly reducing the time taken to process each line.
  • Implementing batch processing techniques to handle multiple lines in a single operation, rather than processing each line individually.

Dependencies

This module depends on the stock module to function correctly.

Installation

To install this module, simply add it to your Odoo instance and update the module list. Once installed, the module will automatically apply the performance optimizations to the stock management system.

Usage

After installing the module, there are no additional steps required to use the optimizations. The module will automatically enhance the performance of GRN processing in the background.
